# 🧠 AI Doctor Chatbot Suite | Powered by LLMs & Streamlit

Welcome to **AI Doctor Chatbot Suite**, a collection of AI-powered medical assistants built using advanced language models and deployed with Streamlit. Each bot is tailored to a specific medical specialization, offering preliminary consultation-style interaction for users seeking quick and informative medical insights.

## 💡 Project Overview

This suite aims to simulate intelligent and specialized medical consultations for users by asking a series of adaptive questions and generating helpful responses using **Groq LLM**. It is an innovative approach to demonstrate the integration of:

- 🧠 **LLM-based conversation (Gemma 2 on Groq)**
- 🧾 **Dynamic question generation based on input**
- 🖼️ **Clean UI using Streamlit**
- 🩻 **Domain-specific advice for each specialty**
- 📜 **Session history tracking**

---

## 📦 Technologies Used

| Tool | Role |
|------|------|
| **Python** | Backend logic and session handling |

| **Groq LLM (Gemma 2)** | Fast, low-latency conversational AI |
| **.env Support** | API Key security |

- ✅ Adaptive question flow depending on user responses
- ✅ Specialization-specific language for each doctor
- ✅ Groq-hosted LLMs ensure fast and reliable responses
- ✅ Stylish and responsive UI with user-bot chat interface
- ✅ History log for past diagnoses/suggestions

## 🎯 Purpose & Impact

This project demonstrates how LLMs can be leveraged in **healthcare support systems**. While not a replacement for real doctors, these bots can:

- Assist in **preliminary symptom analysis**
- Provide **structured advice & awareness**
- Serve as **education tools** for patients or med-tech learners

## 🚀 How to Run Locally

```bash
git clone https://github.com/your-username/ai-doctor-suite.git
cd ai-doctor-suite
pip install -r requirements.txt
streamlit run app.py
```

Replace `app.py` with the respective specialization file.
